# Canisell

Pay-per-call risk verdicts (SAFE / CAUTION / DANGER) for newly launched ERC-20 tokens on Base, paid in USDC over x402. Working name.

- `api/`: the API (Hono, Cloudflare Workers), the MCP server and tests. See [api/README.md](api/README.md).
- `landing/`: static landing page and listing texts (nothing published yet).
